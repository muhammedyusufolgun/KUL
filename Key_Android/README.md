# Key — Kriptografi Android

Blogdaki Akıllı Kriptografi Aracı'nın HTML/JavaScript uygulaması çevrimdışı Android WebView içine alınmıştır. Metin işlemleri ve görsel işlemleri cihazda çalışır. Gelişmiş/çok aşamalı seçenek alanı kaldırılmıştır. Metin girişinin altına görsel seçme ve önizleme alanı eklenmiştir.

- Uygulama adı: Kriptografi
- Başlatıcı etiketi: Key
- Arka plan: açık kırmızı tonlar
- Min Android: 6.0 (API 23)

Android Studio'da açıp Gradle Sync sonrası `app > Build > Build APK(s)` ile derleyin. Derleme ortamı sağlanmadığından bu paket içinde imzalı APK bulunmamaktadır.
